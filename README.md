# AI Receptionist — מזכירה וירטואלית

אפליקציית React (Create React App) בעברית, בכיווניות RTL, שמציגה מזכירה
וירטואלית חכמה לעסק שירות. הצ׳אט עובד כולו בצד הלקוח — ללא שרת וללא מפתח API —
ומשיב לשאלות לפי התאמת מילות מפתח מתוך קובץ התוכן `src/data.js`.

## הרצה מקומית

```bash
npm install
npm start
```

האפליקציה תיפתח בכתובת [http://localhost:3000](http://localhost:3000).

לבנייה לפרודקשן:

```bash
npm run build
```

## התאמה אישית

כל תוכן העסק — שם, סלוגן, שעות פעילות, טלפון, כתובת, אימייל, רשימת שירותים
ומחירים, שאלות נפוצות ותשובות מהירות — נמצא בקובץ אחד בלבד: `src/data.js`.
מחליפים את נתוני הדוגמה בפרטים האמיתיים של העסק וזהו.

## תכונות

- ממשק עברי מלא עם `dir="rtl"` ו־`lang="he"`.
- צ׳אט צד־לקוח עם התאמת מילות מפתח, תשובות מהירות לחיצות, גלילה אוטומטית
  והישלח במקש Enter.
- רשימת שירותים ומחירים, אקורדיון שאלות נפוצות נגיש, וטופס בקשת תור.
- עיצוב מובייל־ראשית ב־CSS בלבד, ללא ספריות UI וללא פונטים חיצוניים.
- נגישות: תוויות לשדות, אקורדיון וצ׳אט ניתנים להפעלה במקלדת, ניגודיות צבעים תקינה.
